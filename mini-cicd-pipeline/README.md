# Mini CI/CD Pipeline Using Shell Scripting

## Overview

A simple CI/CD pipeline built using Bash Shell Scripting that automates testing, building, deployment, backup, rollback, and logging.

## Features

- Run tests before deployment
- Create application build
- Deploy application automatically
- Create deployment backups
- Rollback to previous version
- Generate deployment logs and reports

## Technologies Used

- Linux
- Bash Shell Scripting
- Git
- Python

## Project Structure

```text
mini-cicd-pipeline/
├── app
├── build
├── deployment
├── backups
├── logs
├── deploy.sh
└── rollback.sh
```

## Run

```bash
chmod +x deploy.sh rollback.sh

./deploy.sh
./rollback.sh
```
