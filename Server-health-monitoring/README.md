# 🚀 Server Health Monitoring System

A Bash shell scripting project that monitors Linux server health through a menu-driven interface. The script provides real-time system information and helps administrators quickly assess server performance.

## Features

* Check Disk Usage
* Check Memory Usage
* Check CPU Load
* Check System Uptime
* Check Current User
* Check Hostname & IP Address
* View Running Processes
* View Top CPU/Memory Consuming Processes
* Generate Health Report


## Run the Script

```bash
chmod +x server_health_monitor.sh
./server_health_monitor.sh
```
